# Sector Pulse decorative background assets

## NSE building photograph

`nse-building-zadeus.jpg` is **National Stock Exchange of India 2.jpg** by
[zadeus](https://www.flickr.com/photos/zadeus/404721392/), sourced from
[Wikimedia Commons](https://commons.wikimedia.org/wiki/File:National_Stock_Exchange_of_India_2.jpg).
Licensed [CC BY-SA 2.0](https://creativecommons.org/licenses/by-sa/2.0/).
The distributed JPEG is unchanged. CSS displays it cropped to the viewport,
shaded and faded; any adapted photograph rendering remains under
CC BY-SA 2.0. Attribution is displayed in the portal/dashboard footer.
No endorsement by the photographer or NSE is implied.

## Bull and bear artwork

`bull-bear-algo.png` is AI-generated decorative artwork created for Sector Pulse.
The emerald-green bull and ruby-red bear form a separate transparent background layer, not a trading signal or broker
branding. CSS fades the artwork behind the existing dark panels; chart canvases
and controls retain their readable foreground surfaces.

## Currency motifs

`currency-motifs.svg` is original decorative vector artwork showing dollar ($)
and Indian rupee (₹) coin motifs. These faint background symbols are not prices,
balances, signals or currency forecasts.
