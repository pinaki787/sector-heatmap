# As-of-live source release — 21 November 2026

This release promotes the shared Sector Pulse source to main and retains the
different source versions present in the six hosted broker workspaces at capture.
It preserves the current implementation rather than importing unrelated changes
from older feature branches.

## Source identity

- Shared application baseline: c360b579e87b40fa7eb57f55cac2a4662c8b811d.
- Source variant manifest: deploy/live-source-snapshots/2026-11-21/manifest.json.
- The manifest records its exact capture time, baseline commit, workspace identity,
  broker, port, missing source paths and checksummed overrides.
- Objects are deduplicated by SHA-256. They retain their original file extensions
  for inspection.
- The snapshot covers source on disk, not Python modules already loaded into
  running processes. No claim is made that every process had reloaded every file.

## Included differences

The shared source includes chart workspaces, drawings and studies, shared Pine
indicators, account-owned chart trading workflows, Renko policies and recovery,
AI options strategy source, account selection and multi-account tickets, broker
reports, holdings and investment features, Handoff/screener/report-delivery
changes, regression tests, research source and documentation.

Deployed variants remain separate from the shared defaults. The release does not
replace the live account sources, restart any process or activate any trading
workflow. It excludes credentials, sessions, broker account state, orders,
positions, market datasets, generated evidence and in-memory process state.

- A source-only FYERS restore was compared against every captured FYERS override;

  The authentication fix discussed in chat is not part of this release.

## Inspect and recover source

From a checkout containing the baseline commit:

    python scripts/live_source_snapshot.py verify deploy/live-source-snapshots/2026-11-21

To reconstruct a captured source variant into a new, offline directory:

    python scripts/live_source_snapshot.py restore deploy/live-source-snapshots/2026-11-21 --workspace WORKSPACE_FROM_MANIFEST --destination /tmp/sector-pulse-source-review

The destination must not exist. Recovery does not supply credentials or runtime
state and does not launch or deploy anything. Broker connections require their
existing private configuration; never commit that configuration.

## Branch workflow

Main is the integration baseline after this release. Future work uses a short-lived
feature branch and one pull request describing behavior, tests and known limits.
Deployment/activation is a separate operation with account-specific verification.

The older durable-analysis-jobs, motilal-authentication-fix, renko-checkbox-sizing
and renko-rsi-portable branches have divergent commit histories. They are retained
for reference, not merged blindly into this as-of-live snapshot. Their commits
must be compared for equivalent implementation before any future incorporation
or deletion.
