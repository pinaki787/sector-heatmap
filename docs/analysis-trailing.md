# Screener and Analysis Handoff trailing controls

Both existing sections include an Automatic trailing protection panel. They inherit section visibility and permissions; portfolio operations retain the existing authenticated Holdings Review permission and exact account checks. No new sidebar view, permission, background schedule or automatic enablement is introduced.

Protection account selection is explicit and saved per section. Only configured broker accounts with an implemented native route are offered. Current broker support is documented in multi-broker-trailing.md: Dhan delivery/MTF, FYERS CNC cash holdings, Motilal unencumbered POA cash DP holdings, and Delta verified linear futures. The panel reads a fresh owned portfolio through the existing persistent analysis job, displays gross P&L and the completed-daily candidate stop, and opens the shared monitor controls for exact native identity. Unfilled recommendations, shorts, intraday and options cannot enable this protection route. Recommendations are not treated as broker fills. FYERS Auto Handoff fast exit monitoring and native Smart orders remain separate and unchanged.

The shared monitor defaults to 60 minutes, permits 30/60-minute updates while active, sleeps outside verified exchange sessions and requires explicit consent plus the preview-specific confirmation phrase. Page load, account selection and Review held positions do not enable monitoring or send orders. Stop keeps the last broker stop. Saved output is source/account scoped; stale reports require a fresh review before new enablement. Existing monitor status and Stop remain accessible when analysis gets stale or changes to Hold.

Validation: node helper tests cover account/action isolation, source restoration, eligibility and continued status access when recommendations change. Broker mutation tests use fake clients. Hosted desktop and narrow layout checks completed in both existing sections; narrow tables use position cards to keep the action visible. Read-only reviews in Screener and Handoff both returned the exact Dhan MTF holding; Handoff enablement preview was verified with consent unchecked and Enable disabled. Saved account/review restoration was verified after reload. No trade is placed as a feature test.
